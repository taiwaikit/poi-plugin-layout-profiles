# 布局方案 · poi-plugin-layout-profiles

给 poi 加一层「布局预设」：把窗口尺寸位置、界面缩放、游戏区分辨率、横竖布局、
标签栏方向、概览面板摆放存成多套方案，一键或一个快捷键切换。

---

## 它是给谁用的

三种人最需要它：

1. **双屏 + 副屏竖放**：平时在副屏竖着看，回来用主屏横着打，每次都要重拖窗口、重设缩放。
2. **远程串流玩家**（Moonlight / Parsec / ToDesk / RDP）：人在外面，串流端的虚拟分辨率跟家里
   屏幕对不上，poi 要么小得看不清字，要么大得看不全。
3. **经常换窗口形态的人**：全屏看演习、小窗挂远征、半屏边看边干别的。

poi 本身会记住最后的位置和缩放，但只有**一套**。这套记忆既不分屏幕，也不管你是竖着还是横着，
切换形态时只能手工重调。

## 它做了什么

一张方案卡片里打包了这些东西：

| 存的东西 | 对应 poi 的配置 |
| --- | --- |
| 窗口位置与尺寸、是否最大化 | `poi.window` |
| 界面缩放 | `poi.appearance.zoom` |
| 游戏区固定分辨率 | `poi.webview.width` / `useFixedResolution` |
| 横排 / 竖排 | `poi.layout.mode` / `reverse` |
| 游戏区与面板的比例 | `poi.webview.ratio.*` |
| 标签栏方向与网格 | `poi.tabarea.*` |
| 概览面板的卡片摆放 | `poi.mainpanel.layout`（lg/md/sm/xs/xxs 五档断点表） |

切换时按固定顺序写回去，poi 自己监听 `config.set` 并即时重排，不需要重启，也不需要改 poi 任何文件。

## 功能一览

- **多套方案，一键切换**，切换即时生效。
- **全局快捷键**：`Ctrl+Alt+1` 这种组合，串流画面里也能按。
- **启动参数 / 环境变量**：`poi.exe --layout-profile=串流横屏`，可以做两个桌面快捷方式。
- **启动时套用默认方案**：标记哪套是默认，开机自动进那个形态。
- **三种窗口定位**：记住坐标 / 铺满所在屏 / 等比缩放，换屏幕、换分辨率都不会跑丢。
- **窗口防丢**：串流端改分辨率后窗口跑到屏幕外时，自动拉回主屏。
- **二次确认**：覆盖和删除都要连点两下，触摸屏上也不会误删。
- **回收站**：删掉的方案保留最近 8 条，随时捡回来。
- **导入导出**：JSON 文件，换机器时直接搬。
- **实时状态条**：面板顶部一直显示"当前：横屏 · 125% · 游戏区 1320px · 1060×1043"，切完能立刻对照。

## 典型配置

| 方案 | 定位方式 | 缩放 | 游戏区 | 用途 |
| --- | --- | --- | --- | --- |
| 家里副屏 | 记住坐标 | 125% | 720px | 竖屏挂着，看远征和任务 |
| 串流横屏 | 铺满所在屏 | 100% | 1280px | 外面用手机/平板串流 |
| 小窗挂机 | 等比缩放 | 90% | 自适应 | 边干活边收远征 |

快捷键分别绑 `Ctrl+Alt+1/2/3`，盲按都能切对。

## 和 poi-plugin-new-window 的区别

那个插件是另外开一个只装游戏画面的窗口，用来单独调分辨率；它不管主界面的布局、缩放、标签栏，
也不管概览面板。两个插件可以共存，各管各的。

## 兼容性

- poi 12.0.1 实测通过。
- poi 10 / 11 做了 `electron.remote` 与 `@electron/remote` 的双代兼容，理论上能装，但没有实测。
- Windows 上验证；macOS / Linux 未测试。

## 已知限制

- 串流软件自身如果做了拉伸（Moonlight 的缩放选项），poi 这边设对了也会被二次处理，
  建议串流端设"原始分辨率 + 保持宽高比"。
- 同一断点宽度下只能存一套面板坐标：两套方案若都落在 `lg` 宽度，会互相覆盖该档布局。
- 面板内文案目前是中文，插件列表里的标题/描述做了英文与日文翻译。

## 数据在哪

```
%APPDATA%\poi\layout-profiles\profiles.json
```

插件升级、重装都不会动它。写入是原子替换（先写 `.tmp` 再 rename），崩溃不会写出半截文件；
真读到坏文件时会备份成 `profiles.broken.json` 而不是直接清空。
