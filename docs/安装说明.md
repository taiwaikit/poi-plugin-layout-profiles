# 安装说明

插件名：`poi-plugin-layout-profiles`
适用于 poi 10 及以上版本（12.0.1 上实测）。

---

## 方式一：poi 插件管理器（推荐）

1. 打开 poi，右侧标签栏拉到最右，点齿轮进入 **设置**。
2. 切到 **插件** 页，找到手动安装的输入框。
3. 填入包名：

```
poi-plugin-layout-profiles
```

4. 点安装，等进度条走完，**重启 poi**。
5. 标签栏里出现「布局方案」即安装成功。

## 方式二：命令行

poi 的插件就是一个 npm 包，装在它自己的 `plugins` 目录里：

```bat
cd %APPDATA%\poi\plugins
npm install poi-plugin-layout-profiles
```

装完重启 poi。

## 方式三：离线包

拿到 `poi-plugin-layout-profiles-0.2.0.tgz` 后：

```bat
cd %APPDATA%\poi\plugins
npm install "路径\to\poi-plugin-layout-profiles-0.2.0.tgz"
```

---

## 第一次使用

1. **保存一套方案**：把 poi 调成你想要的样子（拖窗口、改缩放、改游戏区宽度、切横竖），
   在「布局方案」页输入名字（留空会自动命名，例如「竖屏 125%」），点 **保存当前**。
2. **切换**：点方案卡片右上角的「切换」。切换是即时的，不用重启。
3. **设快捷键**：点「点击设置快捷键」，然后按 `Ctrl+Alt+1` 这类组合。
   全局快捷键在串流画面里也能按，这是你在外面最主要的操作入口。
4. **切换位置**：卡片上的下拉框决定这套方案怎么定位窗口。
   - 「记住坐标」：回到保存时的绝对坐标，适合双屏固定摆放。
   - 「铺满所在屏」：填满那块显示器，串流端分辨率变了也不会跑偏。
   - 「等比缩放」：按当前屏幕比例缩放保存的尺寸。

## 更新

插件管理器里点更新按钮即可（从 npm 装的情况下）。用 JUNCTION 链接的开发安装不会显示更新。

## 卸载

插件管理器里点垃圾桶；或手工删掉两个位置：

```bat
cd %APPDATA%\poi\plugins
npm uninstall poi-plugin-layout-profiles
```

方案数据在 `%APPDATA%\poi\layout-profiles\profiles.json`，卸载不会删除。想彻底清干净就手动删掉这个目录。

## 安装不上怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 插件列表里没有 | 没重启 poi | 重启 |
| 显示「已损坏」 | 加载报错 | 看 `%APPDATA%\poi\logs` 里最新日志，把报错发出来 |
| 装完标签栏没有新页 | 插件被禁用 | 插件列表里确认开关是打开的 |
| 点安装报网络错误 | npm registry 访问不了 | 换网络或配 `npm config set registry https://registry.npmmirror.com` |
| 快捷键按了没反应 | 被别的程序占用 | 面板里该方案会标红提示，换一组组合键 |
